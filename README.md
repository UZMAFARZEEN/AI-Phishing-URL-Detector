# AI-Powered Phishing URL Detector

## Problem
Phishing attacks are one of the most common cyber threats. Users often struggle to identify malicious links.

## Solution
This project uses Machine Learning to analyze URL characteristics and predict whether a URL is legitimate or phishing.

## Features
- URL Analysis
- Phishing Detection
- Confidence Score
- Risk Factor Identification
- Streamlit Web Interface

## Tech Stack
- Python
- Streamlit
- Scikit-learn
- Pandas
- Random Forest

## Run Locally

```bash
pip install -r requirements.txt
python -m streamlit run app.py
```
